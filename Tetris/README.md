# Tetris

A classic Tetris game implemented in Python using Pygame.

## Features
- Tetromino movement and rotation
- Line clearing and scoring
- Game over detection
- Keyboard controls

## Requirements
- Python 3.x
- Pygame

## Installation
1. Install Python 3.x from https://www.python.org/
2. Install Pygame:
   ```sh
   pip install pygame
   ```

## Running the Game
```sh
python main.py
```

Enjoy playing Tetris!
